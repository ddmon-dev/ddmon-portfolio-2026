## 개요

자동차 썬팅 필름 제조사 솔라가드의 프리미엄 브랜드 파노라마 필름의 론칭에 따라 브랜드 홈페이지와 시공점 · 지역거점 대상 발주 관리 서비스, 본사 · 지역거점 대상 운영 어드민을 구축한 프로젝트입니다.

알지비커뮤니케이션즈 재직 당시 PM 및 전체 단독 개발을 담당하였으며, 오픈 후 전국 80개 이상의 시공점에서 사용중이며 수 천건의 보증서가 서비스를 통해 발급되고 있습니다.

퇴사 이후에는 프리랜서로서 고객사로부터 의뢰를 받아 기능 개선 및 유지보수를 진행하였습니다.

## 담당 범위

- 요구사항 정리, 화면 · 데이터베이스 · 프로젝트 구조 설계
- 브랜드 홈페이지, 시공점 발주 서비스, 운영 어드민 단독 개발
- 배포 환경 구성, 운영 중 기능 개선 및 유지보수

## 주요 사례

### 개발 · 운영 리소스를 고려한 기술 스택 선정

#### 문제 상황

- 프론트엔드 개발자가 풀스택으로 전체 개발이 요구됨
- 개발 리소스 대비 납기 일정의 제한
- 고객사에 프로젝트 운영 전문 인력의 부재

#### 문제 해결

- 백엔드 및 데이터베이스 구축, 운영 리소스 부담을 낮추기 위해 Baas 서비스 Supabase 채택
- 서버 액션, 컴포넌트 기반으로 풀스택 개발이 가능한 Next.js 14 app router 채택
- 배포 용이성 및 운영 리소스 절감 목적으로 Next.js 웹앱 배포 환경으로 Vercel 채택

#### 결과

- 납기 내 서비스 개발 완료 후 정상 출시
- Supabase pro 요금제 할당량 범위에서 운영중
- Vercel 환경은 추가된 특정 기능 이슈로 자체 서버 구축 및 배포로 대체

### 알림톡 기능 추가로 인한 배포 이슈 해결

#### 문제 상황

- 운영 중 발주, 보증서 발급 시 등 Kakao 알림톡 발송 기능 추가 요구
- Vercel pro 요금제의 고정아이피 미제공 이슈로 알림톡 api 사용 불가 상황 발생

#### 문제 해결

- 변경 빈도가 낮은 API이므로 Vercel 인프라를 활용하면서 별도의 작은 발송 서버만 관리하면 운영 부담과 비용을 줄일 수 있을 것으로 예상
- 가비아 클라우드의 저사양 서버 구매 후 알림톡 발송용 API 서버 구축을 고객사에 제안
- 고객사의 인프라 분산 부담으로 가비아 클라우드 ubuntu 컴퓨팅에 Next.js 앱 운영 서버 구축으로 결정
- 알림톡 API에서 발급 받은 인증 토큰을 만료 전까지 캐시하고 재사용하도록 API route 구현
- 도메인 DNS 설정과 Nginx Proxy Manager의 리버스 프록시 · HTTPS 구성, PM2 기반 프로세스 관리 환경 구성하여 Ubuntu 서버에 배포

#### 결과

- 알림톡 기능 정상 추가 완료
- 가비아 클라우드 컴퓨팅 환경에서 특이 이슈 없이 운영중

### 시공점 포인트 이력 관리 기능 추가

#### 문제 상황

- 시공점 포인트가 단일 필드로 잔액만 갱신되고 있음
- 운영 중 적립 · 사용 내역 관리 필요성이 대두되고 담당자가 엑셀로 변동 내역을 수기로 기록
- 서비스 내 시공점 포인트 이력 관리 기능의 추가 요청 발생

#### 문제 해결

- 전환 시점의 잔액을 이월 내역으로 남기고, 이후 발생하는 포인트 변동부터 기록하도록 고객사와 협의
- 주문 적립 · 구매 차감 · 환불 · 관리자 조정에서 동일한 DB 함수를 호출하도록 포인트 변경 처리 통합
- 포인트 잔액 갱신, 변동 이력 저장을 트랜잭션으로 처리, 원자성 확보

#### 결과

- 기존 잔액 누락 없이 히스토리 시스템으로 전환 완료
- 관리자가 어드민 화면에서 시공점별 포인트 내역을 관리, 엑셀 수기 관리 대체
