## 개요

솔라가드 건축용 필름의 시공 보증서 발급 · 관리를 위해 운영 담당자용 어드민과 소비자용 보증서 조회 사이트를 구축한 프로젝트입니다.

기존에 개발한 어드민 보일러플레이트를 활용해 조회 사이트와 어드민을 단독 개발하였으며, 현재 고객사의 보증서 발급 업무에 사용되고 있습니다.

## 담당 범위

- 조회 사이트 · 어드민 UI 디자인, 화면 · 데이터베이스 · 프로젝트 구조 설계
- 보증서 조회 · 발급 · 관리, 엑셀 대량 발급 및 오류 데이터 수정 UI 개발
- PDF 문서 생성과 조회 API 개발, 전체 서비스 단독 개발 · 배포

## 주요 사례

### 보증서 대량 발급 및 오류 데이터 수정 UI 개발

#### 문제 상황

- 고객사의 보증서 대량 발급 기능 개발 요구사항 접수

- 보증서 발급에 필요한 입력 항목과 데이터 형식을 맞춰야 함
- UX를 고려했을 때, 오류가 있는 데이터를 확인 · 수정한 뒤 발급할 수 있는 흐름 필요

#### 문제 해결

- 사용자가 입력 항목과 형식을 쉽게 맞출 수 있도록 엑셀 템플릿 생성 · 다운로드 기능 제공
- 업로드된 데이터는 zod 검증 후 오류 셀을 화면에서 직접 확인하고 데이터를 수정 가능한 UI 제공
- 기획 및 설계 기반으로 AI 에이전트를 활용하여 기능 구현 및 브라우저 기반 테스트 자동화

#### 결과

- 엑셀 업로드부터 오류 데이터 확인 · 수정, 보증서 대량 발급까지 이어지는 기능 제공
- 엑셀 입력 오류 케이스별 검증 및 수정 동작 테스트 완료

### 보증서 문서 PDF 생성 및 프로젝트 구조 설계

#### 문제 상황

- 조회 사이트와 어드민, 두개의 프로젝트에서 동일한 보증서 양식이 사용되어야함
- 직접 관리하지 않는 고객사 서버에 배포하므로 PDF 생성에 필요한 설치 · 실행 환경의 관리 부담 고려

#### 문제 해결

- 별도 Chrome 설치 · 실행 관리가 필요한 Puppeteer 대신 `@react-pdf/renderer` 채택
- `@react-pdf/renderer` 기반 PDF 전용 컴포넌트로 보증서 문서 양식을 구현하고 어드민 프로젝트에 배치
- 어드민은 브라우저에서 직접 PDF를 생성하고, 소비자용 조회 사이트는 어드민 서버 API로부터 PDF Blob을 응답받아 사용하도록 구성

#### 결과

- 서버 사이드에서 브라우저 프로세스 관리 없이 PDF 생성 기능 제공
- DB 접근과 보증서 생성 로직 및 컴포넌트를 어드민에서 관리하여 조회 사이트의 구현 · 유지보수 범위 축소
