## 개요

사내 실무진 및 관리자 업무를 위한 사내 백오피스를 구축하고 운영했습니다.

기존 PHP 기반 프로젝트 관리 도구와 분산된 업무 데이터를 바탕으로 Next.js 기반 백오피스를 신규 설계 · 구축하였으며, 대표 · 영업팀의 요구사항을 정리하고 별도 디자인 시안 없이 화면과 기능을 직접 설계 · 개발했습니다.

MVP로 구축 후 기능 확장 및 디자인, UI 및 프로젝트 구조 리팩토링을 통해 프로젝트 관리, 견적서 등의 영업 도구 활용, 고객 데이터 관리 등 사내 업무 효율성을 향상하고자 하였습니다.

## 담당 범위

- 대표 · 영업팀 요구사항 정리, 별도 디자인 시안 없이 화면과 기능 설계
- 프로젝트 · 고객 · 견적 관리와 자사 홈페이지 콘텐츠 관리 개발
- 데이터베이스 · 프로젝트 구조 설계, 배포 · 운영 · 유지보수

## 주요 사례

### 견적서 작성 업무의 웹 기반 전환

#### 문제 상황

- 엑셀로 작성된 견적서를 영업 팀 내 개인 PC에 보관함에 따라 견적 내역 공유와 견적 데이터 분석의 어려움 발생
- 외부 반출 문서 특성상 견적서 디자인 및 규격, 산출물 품질 확보가 요구됨
- 기존의 작성 방식의 관성을 극복할 수 있는 사용자 경험 제공이 필요

#### 문제 해결

- 화면에서 견적서를 작성하고 실시간 미리보기와 PDF 출력을 확인할 수 있도록 구성
- PDF 산출물 품질을 고려하여 Puppeteer 채택하여 실시간 미리보기 컴포넌트의 HTML과 CSS를 서버에 전달하여 PDF를 생성하도록 구성
- 기존 견적 복사 및 템플릿 활용으로 새 견적의 작성 부담을 줄이고 기존 업무 방식에서의 전환 지원

#### 결과

- 기존 엑셀 견적 작성 방식을 웹 작성 · 공유 방식으로 완전히 대체

### 디자인 시스템 개선 및 프로젝트 구조 리팩토링

#### 문제 상황

- 목록 · 검색 · 상세 조회 및 입력 관련 상태 및 로직이 모듈 Context에 모두 작성됨
- 기능이 추가됨에 따라 Context에 모인 로직을 모듈별로 수정하는 비용 발생
- 자체 개발 UI 컴포넌트로 인해 UI 관리 및 신규 기능 대응의 어려움
- 사용자 입력 데이터 검증 스키마가 클라이언트와 서버에 분리되어 있음

#### 문제 해결

- 모듈별 상태를 Context 중심에서 컴포넌트 책임으로 분산
- zod 스키마를 클라이언트의 react-hook-form과 서버 액션에서 공유하여 스키마 관리 부담 축소
- Tailwind CSS와의 호환성 및 자체 UI 컴포넌트의 유지보수 부담을 고려하여 shadcn/ui 채택
- 도메인 화면별 디자인 시스템 및 레이아웃을 설계하여 신규 화면 추가에 대한 UI 개발 효율성 확보

#### 결과

- 화면별 스타일 관리 효율성 확보
- 신규 기능 및 화면 추가 비용 절감
